# Prompting Game

Students edit weak prompts, compare real AI answers and judge them against prepared requirements. Two Beginner practices are available: a class invitation and PDF submission instructions. Completing both opens a hint-free Beginner final; an unsuccessful final returns to supported practice before the alternate. Real generation, feedback, both correction paths, saved points and reopening passed live browser checks. The current 20-request daily app cap can stop new assessments; it resets at midnight UTC. The full game and account backup remain incomplete.
