# Beginner practice 1: make the request clear

Status: prepared example awaiting teacher review. Fictional task facts, not real student data. Version: beginner-01-v1.

## Student-facing task

Write a short class announcement using AI. The announcement must tell first-year students that a voluntary prompt practice session is on Friday at 2 PM in Room 204, lasts 30 minutes, and requires bringing a charged phone. Use a friendly tone, no more than 80 words, and do not invent a registration link or other facts.

## Starting prompt

Write something about our AI session.

## Original example answer

Join our exciting AI event soon! Meet experts, discover powerful tools, and register online today. Everyone is welcome.

This is an illustrative prepared answer, not a recorded model response. It is missing essential details and invents experts and online registration.

## Essential requirements for assessment

- A class announcement for first-year students, not an essay or general AI explanation.
- Friday, 2 PM, Room 204, 30 minutes, charged phone and voluntary attendance are conveyed accurately.
- Friendly wording within 80 words.
- No invented event facts, registration links or required attendance.
- The student's judgment checks actual task fit. It identifies material missing or invented information when present, rather than assuming a well-written answer is useful.

Exact prompt wording and a role instruction are not required. A request can refer to the supplied task facts when they are actually available to the answering model. Keep those facts available to the model in both initial and revised requests; do not manufacture an information disadvantage.

## After feedback

If the prompt omits requirements, edit it and explain the change. Generate an answer, then judge that specific answer.

If the prompt already covers the task but the judgment misses an answer defect, leave the prompt unchanged. Correct the judgment of the existing answer and explain why.

A point requires a relevant correction, a sound explanation and accurate answer judgment. A fully correct initial attempt can also earn it. The task is ready for practice content review, not approved for automated scoring.

## Worked example, revealed only under the practice retry rule

Prompt: Write a friendly announcement for first-year students, at most 80 words. Use these facts: voluntary prompt practice, Friday at 2 PM, Room 204, 30 minutes, bring a charged phone. Include all details and do not invent facts or a registration link.

Illustrative answer: First-year students: join an optional prompt practice session this Friday at 2 PM in Room 204. We will practise for 30 minutes. Bring a charged phone so you can try the activities. Come along if you would like to improve how you use AI.

Explanation: The request specifies the audience, format, facts and limits. The answer includes the supplied details without invented registration. The student must still check any actual generated answer; copying this prompt does not guarantee a correct output.

## Manual first test

Use an authorized AI chat or API. Give it the task, requirements and a sample submission from feedback-review.md. Ask for one feedback gap with evidence, a prompt-versus-judgment correction path and a point decision with reasons. Compare that output against teacher judgments recorded before running AI.

Save the prompt, model/version if available, output and teacher disagreements. A manual chat test can check teaching behavior, but API access, cost and backend reliability remain separate checks. Do not use the assistant that wrote these examples as an independent teacher reviewer.
